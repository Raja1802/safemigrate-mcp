# SafeMigrate MCP Publishing & Distribution Playbook

Step-by-step guide to publishing SafeMigrate MCP to the primary Model Context Protocol directories and developer registries.

---

### 1. Awesome-MCP-Servers (GitHub PR)
- **Target Repository**: `punkpeye/awesome-mcp-servers`
- **Action**: Fork the repository, create a branch `feat/add-safemigrate-mcp`, and edit `README.md`.
- **Location in README**: Add under the **"Database"** and **"Developer Tools"** sections:
```markdown
- [SafeMigrate MCP](https://github.com/raja1802/safemigrate-mcp) - AST-based zero-downtime database migration guard and auto-rewriter for PostgreSQL and MySQL (prevents AI agents from locking tables).
```
- **Git Commit Message**:
```bash
git commit -m "feat: add SafeMigrate MCP database guard"
```
- **PR Title**: `Add SafeMigrate MCP (Zero-Downtime Database Migration Guard)`
- **Submit PR**: Open pull request to `punkpeye/awesome-mcp-servers:main`.

---

### 2. PulseMCP (pulsemcp.com)
1. Navigate to: [https://pulsemcp.com/submit](https://pulsemcp.com/submit)
2. Fill in the submission form:
   - **Name**: SafeMigrate MCP Guard
   - **Repository URL**: `https://github.com/raja1802/safemigrate-mcp`
   - **Description**: Deterministic AST analyzer that intercepts database migrations generated by coding agents, flags table-locking queries, and provides zero-downtime rewrites.
   - **Pricing Model**: Freemium / Paid License Key ($19/mo via Polar.sh)
   - **Transport**: SSE / HTTP (`https://safemigrate-mcp.fly.dev/mcp`) & Local `stdio`
   - **Tags**: `postgres`, `mysql`, `database`, `migrations`, `safety`

---

### 3. Smithery.ai (smithery.ai)
1. Sign in with GitHub on [https://smithery.ai](https://smithery.ai).
2. Click **"Add Server"** $\rightarrow$ select or paste repository `raja1802/safemigrate-mcp`.
3. Smithery automatically detects the root [`smithery.yaml`](./smithery.yaml) manifest:
   - Docker build context is validated.
   - Entrypoint `src/server/main.py` is tested.
   - Sandboxed test instance is automatically provisioned.

---

### 4. Glama.ai (glama.ai/mcp)
1. Navigate to: [https://glama.ai/mcp/servers](https://glama.ai/mcp/servers)
2. Connect your GitHub account.
3. Select `raja1802/safemigrate-mcp` to sync configuration from [`glama.json`](./glama.json).
4. Glama immediately verifies the live endpoint: `https://safemigrate-mcp.fly.dev/mcp`.

---

### 5. mcp.so Directory (mcp.so)
1. Go to [https://mcp.so](https://mcp.so) and click **"Submit MCP Server"**.
2. Enter:
   - **Name**: SafeMigrate MCP Guard
   - **GitHub Repo URL**: `https://github.com/raja1802/safemigrate-mcp`
   - **Remote SSE URL**: `https://safemigrate-mcp.fly.dev/mcp`
   - **Categories**: Databases, Code Intelligence, Developer Tools
   - **Pricing**: Open-Source / Self-Hosted + Cloud Hosted ($19/mo)
